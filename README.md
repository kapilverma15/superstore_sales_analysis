# 📊 Superstore Sales Analysis Dashboard

An interactive web-based analytics dashboard built with **Streamlit** and **Plotly** to visualize and analyze retail sales data from the Sample Superstore dataset.

---
## ✨ Features

- **Interactive Filters:** Filter data dynamically by Date Range, Region, State, and City.
- **Sales Insights:** Category-wise bar charts and Region-wise pie charts.
- **Time Series Analysis:** Monthly sales trend line charts to identify seasonality.
- **Hierarchical Visualization:** Interactive TreeMap showing distribution across Region → Category → Sub-Category.
- **Profitability Metrics:** Scatter plot analyzing the correlation between Sales, Profit, and Quantity.
- **Data Export:** View and download filtered datasets directly as CSV files.

---

## 🛠️ Tech Stack

- **Python 3.x**
- **Streamlit** (UI Framework)
- **Pandas** (Data Manipulation)
- **Plotly Express** (Interactive Charts)
